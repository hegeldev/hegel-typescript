# This repository has moved

Hegel for TypeScript now lives in the Hegel monorepo at **https://github.com/hegeldev/hegel**.

| What you're looking for | Where it is now |
|---|---|
| The `@hegeldev/hegel` package (TypeScript frontend) and its platform packages | [`frontends/typescript/`](https://github.com/hegeldev/hegel/tree/main/frontends/typescript) |
| The browser guide | [`frontends/typescript/BROWSER.md`](https://github.com/hegeldev/hegel/blob/main/frontends/typescript/BROWSER.md) |
| libhegel, the engine behind every Hegel frontend | [`libhegel/`](https://github.com/hegeldev/hegel/tree/main/libhegel) |
| Changelog | [`frontends/typescript/CHANGELOG.md`](https://github.com/hegeldev/hegel/blob/main/frontends/typescript/CHANGELOG.md) |
| Bug reports and feature requests | [hegeldev/hegel issues](https://github.com/hegeldev/hegel/issues) |

Nothing changes for users of the package: `@hegeldev/hegel` and the `@hegeldev/hegel-<os>-<arch>` platform packages keep their names on [npm](https://www.npmjs.com/package/@hegeldev/hegel), and the documentation is still at [hegel.dev/typescript](https://hegel.dev/typescript).

## Tags and history

The full history of this repository was merged into the monorepo unchanged, so every commit here exists there too. Releases are tagged by path and version in the new repository:

| Here | In hegeldev/hegel |
|---|---|
| `v0.4.10` | `frontends/typescript/0.4.10` |

Releases made before the move remain available under this repository's [releases](https://github.com/hegeldev/hegel-typescript/releases). New releases, starting with 0.4.11, are published only from hegeldev/hegel.

For general information about Hegel, see https://hegel.dev.
